# Data Collection Protocol (60 Minutes)

## Overall Session Timeline

| Phase | Duration |
|--------|---------:|
| Preparation (consent, questionnaire, sensor setup) | 10 min |
| Task 1: Attention | 15 min |
| Break | 3 min |
| Task 2: Emotion | 20 min |
| Break | 2 min |
| Task 3: Stress | 8 min |
| Debrief | 2 min |
| **Total** | **60 min** |

---

# Task 1: Three-Class Attention Classification

## Classes

- Neutral
- Relaxing
- Concentrating

To balance the dataset, each participant completes **three trials per class** (**9 trials total**).

| Condition | Number of Trials | Duration per Trial |
|-----------|-----------------:|-------------------|
| Neutral | 3 | 1 min |
| Relaxing | 3 | 2 min |
| Concentrating | 3 | 2 min + comprehension question |

The nine trials are presented in **randomized order**. Each trial is separated by a **15-second rest period**.

This produces a balanced dataset with:

- 3 Neutral trials
- 3 Relaxing trials
- 3 Concentrating trials

per participant.

---

# Task 2: Three-Class Emotion Classification

## Classes

- Positive
- Negative
- Neutral

Each participant watches **three clips from each emotion class** (**9 trials total**).

| Condition | Number of Trials | Duration per Trial |
|-----------|-----------------:|-------------------|
| Positive | 3 | 1–2 min |
| Negative | 3 | 1–2 min |
| Neutral | 3 | 1–2 min |

The nine clips are presented in **randomized order** with a **30-second rest period** between clips.

This results in a balanced dataset with:

- 3 Positive trials
- 3 Negative trials
- 3 Neutral trials

per participant.

---

# Task 3: Two-Class Stress Classification

## Classes

- No Stress (resting baseline)
- Stress (mental arithmetic)

Instead of one long recording, the session is divided into **three repeated trials**.

| Condition | Number of Trials | Duration per Trial |
|-----------|-----------------:|-------------------|
| Resting baseline | 3 | 1 min |
| Mental arithmetic | 3 | 1 min |

Each resting baseline period is **immediately followed** by one mental arithmetic period.

This provides:

- 3 Stress trials
- 3 No-Stress trials

for every participant.
